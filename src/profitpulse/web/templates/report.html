Revenue leakage

Each finding compares one branch, product or supplier with its peers using a robust statistical baseline (median and median absolute deviation, which the outlier itself cannot distort). A finding is raised only when the gap is both statistically strong and large enough to matter commercially.

Exposure is the size of the gap to the peer median applied to the entity's own volume. Findings can overlap (a discounting branch also shows a lower margin), so exposures should not be added blindly. Inventory-discrepancy exposure is an upper bound because stock adjustments carry no direction in the source data.

Branch performance

The performance score is the weighted average of five measures, each compared with the other branches using the same robust statistics as the anomaly checks (typical = 0.5, far worse = 0, far better = 1, capped at three robust standard deviations): {% for key, w in weights.components.items() %}{{ key.replace('_', ' ') }} ({{ (w.weight * 100) | round | int }}%{% if not w.higher_is_better %}, lower is better{% endif %}){% if not loop.last %}, {% endif %}{% endfor %}. A branch that is typical on every measure scores about 50, and a big gap costs far more than a small one. Bands: strong from {{ weights.bands.strong }}, watch from {{ weights.bands.watch }}, otherwise weak.
